# Week 7 – Web Application Security Testing

This folder contains the Week 7 assessment reports documenting web application security testing using **Burp Suite, OWASP Juice Shop, and Gobuster**.

### Activities Covered

* Reconnaissance and attack surface mapping
* SQL Injection and Cross-Site Scripting (XSS) testing
* Authentication and parameter tampering tests
* IDOR / Broken Access Control testing
* Directory and endpoint discovery
* Vulnerability analysis and remediation recommendations

### Objective

To gain practical experience in identifying, testing, documenting, and understanding web application security vulnerabilities in an authorized lab environment.

**Environment:** Kali Linux, Burp Suite, OWASP Juice Shop

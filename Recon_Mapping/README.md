**Recon-and-Mapping 
**
Objective:
Perform basic reconnaissance and map the DVWA web application using Burp Suite.

Activities Performed:

Configured Burp Suite Proxy.
Accessed the local DVWA application through Burp's browser.
Captured and analyzed HTTP requests.
Used Target → Site Map to identify application endpoints.
Identified login pages, forms, GET/POST parameters, and application paths.
Documented the web application's basic attack surface.

Target: http://192.168.56.101:4280

Tool Used: Burp Suite Community Edition

Result:
Successfully mapped the main DVWA application structure and identified endpoints for further security testing.
